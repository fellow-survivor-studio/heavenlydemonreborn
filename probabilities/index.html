현재 공개 상태

상품별 확률 공개 전

현재 공개된 확률형 상품 목록과 확률 수치는 없습니다. 임의의 예시 확률을 실제 상품 확률처럼 제공하지 않습니다. 유료 뽑기 판매 전에 게임 내 구매 화면과 이 페이지에 해당 상품의 확률정보를 게시합니다.

이 안내만으로 확률 공개가 완료된 것은 아닙니다. 실제 획득 대상·확률·조건이 게시되기 전에는 해당 유료 뽑기의 구매를 제공하지 않습니다.

상품별로 공개할 정보

  • 상품·배너 이름, 판매·적용 기간과 확률표 버전
  • 획득할 수 있는 아이템과 종류별 확률, 필요한 경우 등급 내 개별 확률
  • 천장·보장 횟수, 초기화 조건 및 배너 간 이월 여부
  • 누적 횟수나 이용 조건에 따라 달라지는 확률과 적용 방식
  • 중복 획득 시 처리, 한정 수량·기간과 구매 제한
  • 여러 단계의 추첨·합성·강화가 있으면 각 단계와 필요한 최종 결과 확률

합계·반올림 표시와 실제 계산 방식의 관계를 명확히 설명합니다. 공개 확률과 실제 지급 로직을 일치시키고 법령이 요구하는 표시 방식을 따릅니다.

변경 및 오류 문의

확률이나 보장 조건이 변경되면 적용 시점과 버전을 안내하고 이전 적용 자료를 보관합니다. 획득 기록과 적용 확률에 의문이 있으면 게임 UID, 상품명, 이용 시각과 내용을 고객지원에 알려주세요.

상품별 확률표가 비어 있거나 링크에 오류가 있으면 구매하지 말고 문의해 주세요. 환불·분쟁 처리 안내도 확인할 수 있습니다.
