이 웹사이트는 GitHub Pages로 제공됩니다. 웹페이지 자체에 광고·방문 분석 SDK, 입력정보를 전송하는 문의 폼 또는 추적 쿠키를 넣지 않습니다. 호스팅 제공자인 GitHub는 접속 시 IP 등 서비스 제공·보안 정보를 자신의 정책에 따라 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.

5. 국외 이전과 데이터 위치

한국 서비스라는 사실만으로 모든 개인정보가 국내에서 처리되는 것은 아닙니다. Firebase Authentication은 공식 안내상 미국에서 운영되며, Cloud Firestore의 게임 저장 위치는 대한민국 서울(asia-northeast3)로 계획합니다. 저장 리전과 인증·서비스 운영정보·해외 접근의 처리 위치는 서로 다를 수 있습니다.

8. 광고·자동 수집·선택권

AdMob SDK는 광고 요청 시 IP 주소, 기기 식별자, 앱 이용·광고 상호작용 및 진단정보를 처리할 수 있습니다. 광고 ID를 사용하지 않는 설정이나 비개인화 광고도 모든 개인정보 처리가 없는 것을 뜻하지 않습니다. 자세한 항목은 Google Mobile Ads 데이터 공개 안내를 참고하세요.

동의가 필요한 처리의 경우 광고 SDK의 수집·요청 전에 목적별 선택을 제공하고 철회 방법을 안내합니다. Android 설정에서 광고 ID를 재설정·삭제할 수 있으나, 이는 회사의 동의 철회·삭제 요청 절차를 대신하지 않습니다. 맞춤형 광고를 거절했다는 이유만으로 기본 게임 이용을 거절하지 않는 방향으로 구성합니다.

홍보성 푸시·이메일은 현재 제공을 확정하지 않았습니다. 도입 시 선택 동의, 수신거부와 필요한 야간 동의 절차를 별도 안내합니다. 기기 알림 권한과 마케팅 수신 동의는 구분합니다.

9. 안전성 확보와 기기 권한

회사와 수탁자는 개인정보 취급자의 접근권한 제한, 인증, 전송 암호화, 개인정보 처리시스템 보호, 기록 관리와 파기 등 적용되는 안전조치를 수행해야 합니다. 게임 서비스 개시 전에 실제 설정과 운영 절차를 확인합니다.

인터넷·네트워크 접근은 로그인·저장·광고·결제에, 결제 관련 기능은 Google Play 구매에 사용합니다. 광고 식별자 관련 권한은 실제 SDK 설정에 따라 처리합니다. 알림 등 선택 권한을 추가할 경우 사용 목적을 안내하고 필요 시점에 요청합니다. 사진·연락처·정밀 위치를 게임에 필수인 정보로 요구하지 않습니다.

10. 연령·개인정보 침해 구제
